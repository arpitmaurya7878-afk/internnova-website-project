# InternNova Homepage Redesign

A responsive, minimal and corporate-style homepage redesign concept for InternNova, built with plain HTML, CSS and JavaScript.

## Features

- Complete homepage with navigation, hero, statistics, internship domains, learning process, benefits, resources, workshops, learning stories, FAQ, CTA and footer
- Responsive desktop, tablet and mobile layouts
- Mobile navigation with keyboard Escape support
- Internship domain filters
- Accessible FAQ accordion
- Scroll reveal animations with reduced-motion support
- Semantic HTML, focus-visible styles, skip link, and basic SEO metadata
- External CSS and JavaScript files; no framework or build step required

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a browser, or use VS Code Live Server.
3. Test the mobile menu, domain filters, FAQ accordion, section links, and external program links.

## Deploy

### GitHub Pages
1. Create a GitHub repository and upload these files to the repository root.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. Wait for GitHub Pages to publish the site.

You can also deploy this static project using Netlify or Vercel by importing the repository; no build command is required.

## Content and brand notes

- The official program links point to `https://internnova.co.in/`.
- Program names and high-level details were based on publicly visible InternNova website content at the time this concept was prepared.
- Statistics are attributed to claims shown on the reference website, and a disclaimer is displayed in the page.
- The student-story area is intentionally written as editorial learning guidance, not as fabricated student testimonials.
- Some resource links currently point to the official homepage as safe placeholders. Replace them with exact official destination URLs if confirmed.
- This is an independent educational/portfolio redesign concept, not the official InternNova website. Use official brand assets only with permission.
